<h1 align="center">Schreibwerkstatt</h1>

<p align="center">
  Schreiben, Lektorat und Buchanalyse mit KI.<br>

  <a href="https://apps.apple.com/app/id6797073919?mt=12">Mac App Store</a>

---

Schreibwerkstatt ist eine Schreib-App für Bücher, Manuskripte und Tagebücher: Editor mit Fokusmodus,
Kapitel- und Seitenverwaltung, Lektorat und Buchanalyse mit KI (Claude oder lokal über Ollama),
Rechtschreibung, Diktat und Vorlesen. Sie läuft gehostet auf
[schreibwerkstatt.app](https://schreibwerkstatt.app) oder selbst gehostet auf dem eigenen Server.

## Projekte

| Repository | Was | Plattform |
|---|---|---|
| [**schreibwerkstatt**](https://github.com/schreibwerkstatt/schreibwerkstatt) | Server und Web-App – das Mutterprojekt | Node.js, SQLite |
| [**focuseditor**](https://github.com/schreibwerkstatt/focuseditor) | Nativer Client für den Fokus-Editor, offline-fähig | macOS |
| [**mobile**](https://github.com/schreibwerkstatt/mobile) | Nativer Client zum Schreiben und Diktieren, offline-fähig | Android |
| [**browser-extension**](https://github.com/schreibwerkstatt/browser-extension) | Webseiten als Recherche-Fundstück oder Quelle erfassen | Chrome |
| [**homeassistant**](https://github.com/schreibwerkstatt/homeassistant) | Server-, Nutzungs- und KI-Kostenmetriken als Sensoren | Home Assistant (HACS) |

Die Clients und Integrationen sprechen mit einem Schreibwerkstatt-Server, gehostet oder selbst betrieben.
Die nativen Editoren laden den Fokus-Editor zur Laufzeit vom Server, damit er nur an einer Stelle gepflegt wird.
